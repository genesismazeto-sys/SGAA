{# Design System — authentication feedback alert (single owner; DS README §2.6g) The one banner every public authentication page (login, password recovery, first access / password reset) uses for a feedback state. Instructions, explanatory text and field hints are never alerts. Tones (styles: static/css/components/auth-alert.css, linked by the page): - `danger` — a refusal or error: Tabler alert-circle, role="alert"; - `positive` — a confirmed success: Tabler circle-check, role="status"; - `info` — a neutral notice that confirms nothing (the recovery request's acknowledgement, a sign-out): Tabler info-circle, role="status". The message is plain text, escaped here; its wording is the caller's.
